Project Overview

The Online Delivery System is a full-stack web application designed to provide a complete food ordering and delivery management experience. The Front-End was developed using React to create a dynamic and responsive user interface, while the Back-End was implemented using Java to manage application logic, user authentication, orders, and database operations. The project showcases full-stack development capabilities by integrating React and Java technologies, applying clean architecture principles, secure API communication, and efficient data management.
